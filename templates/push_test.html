Setup Guide
1
Install pywebpush
Run: pip install pywebpush
2
Generate VAPID Keys
Run once: python -c "from py_vapid import Vapid; v=Vapid(); v.generate_keys(); print(v.public_key)"
This prints your public key and creates private_key.pem.
3
Add to .env
VAPID_PUBLIC_KEY=<your public key>
VAPID_PRIVATE_KEY=<contents of private_key.pem>
VAPID_CLAIMS_EMAIL=mailto:admin@yourdomain.com
4
Register blueprint in app.py
from blueprints.push_bp import bp_push, init_push_table
app.register_blueprint(bp_push)
Then after init_db(app): init_push_table(app)
5
Add push.js to dashboards
Add to teacher_dashboard.html and student_dashboard.html:
<script src="/static/push.js"></script>
Then call: ExamGuardPush.init(userId, role)
6
Trigger from session violations
In cv_engine.py or sessions_bp.py, import and call:
from blueprints.push_bp import send_push_to_teachers
send_push_to_teachers("⚠ High Risk", f"{student} flagged", url=f"/report/{sid}")
