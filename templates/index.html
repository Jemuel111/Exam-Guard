DETECTION CAPABILITIES
What ExamGuard monitors
NO_FACE
Face Absence

Flags when no face is detected for more than 5 consecutive seconds. High severity.

MULTIPLE_FACES
Multiple Persons

Detects when more than one person appears in frame. Critical — immediate alert.

LOOK_AWAY
Gaze Deviation

Eye landmark analysis tracks sustained off-screen gaze beyond 3 seconds.

TAB_SWITCH
Tab Switch

Browser Visibility API detects navigation away from the exam tab. Immediate log.

AUDIO_ANOMALY
Audio Monitoring

Web Audio API detects sustained loud noise or speech patterns above threshold.

RISK_SCORE
Risk Assessment

Weighted behavioral scoring: Low / Medium / High. All flags require human review.
